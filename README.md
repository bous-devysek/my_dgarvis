# garvis

Голосовой ассистент для Windows

**Статус: alpha.** Только Windows 11 x64, рус яз.

## sistem требования
- Python 3.12–3.14 (рекомендуется 3.12)
- 16 ГБ желательно (програма потребляет +- 1.1 гб)
- NVIDIA GPU с 4 ГБ VRAM(мин)
- +- 3,5 ГБ на диске

## Установка
**Откройте рабочий стол** и там терменал (powershell), после введите команды:
Советую скачать python 3.14

```powershell
git clone https://github.com/bous-devysek/my_dgarvis.git
cd my_dgarvis
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python download_model.py
```

если у вас уже есть питон версии > 3.11 то скачивать не надо

если загрузка происходит адски медлено можно попробывать(меньше 100 кб/с): (работает со скростью 1мб/с)

git clone git@github.com:bous-devysek/my_dgarvis.git

После скачивания модели запустите `run_console.bat` двойным кликом
(консоль можно свернуть, но не закрывать).


Дождитесь надписи «готов», включите тумблер и скажи «Джарвис». Дальше 20 секунд можно говорить команды без имени; окно продлевается после каждой команды.

## Немного нужной инфы

Пока что умеет несколько вещей
1) Открывать и закрывать игры из стим (которые есть в файле data/entities.json)
2) Открывать браузер и конкретные страницы (ютуб или гит) (если они есть в файле)
3) Включать и выключать музыку в активном проигрывателе 
(тоесть если открыть спотик или другой аудио проигрыватель то может с ним взаимодейтвовать)

### Как добавлять нужные игры или сайты
Для того чтобы добавить свою игру или сайт надо просто открыть файл data/entities.json и 
вставить туда такую конструкцию:
```
    {
        "canonical": "",
        "kind": "",
        "value": "",
        "process_name": "",
        "aliases": []
    },
```
1) "canonical" название игры/сайта
2) "kind" тип элемента ("game","browser","music")
3) "value" номер игры стим или сылка на сайт
4) "process_name" как называется процес в диспечере если это игра
5) "aliases" то как вы назаете игру, пару примеров (все запросы праходят лематизацию)

Лемматизация — это процесс приведения словоформы к её начальной, словарной форме (лемме) с учетом морфологии и контекста.
